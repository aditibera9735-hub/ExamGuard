# ExamGuard – Smart Examination Monitoring Platform

## Project Overview
ExamGuard is a Smart Examination Monitoring Platform with Integrity Analysis and Reporting System. It collects examination events, stores evidence, monitors suspicious activities, and calculates an explainable integrity score.

## Key Features
- Integrity Event Architecture
- Event Validation and Storage
- Face Monitoring Event Adapter
- Browser Activity Monitoring
- Evidence Management and Audit Logging
- Kafka-based Event Communication
- Configurable Integrity Scoring Engine
- Automated Test Cases

## Technologies Used
- Python
- Flask
- JavaScript
- Apache Kafka
- Docker
- JSON / JSONL
- Pytest

## Project Setup

1. Clone the repository:
   `git clone https://github.com/aditibera9735-hub/ExamGuard.git`

2. Open the project folder:
   `cd ExamGuard`

3. Install dependencies:
   `py -3.13 -m pip install -r requirements.txt`

4. Run the application:
   `py -3.13 app.py`

5. Open in your browser:
   `http://127.0.0.1:5000`

## Run Tests
`py -3.13 -m pytest -v`
